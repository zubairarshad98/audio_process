🎙️ AI-Based Speech Detection and Audio Enhancement System

📌 Project Overview

This project is a BS Final Year Project developed using Python and Streamlit. The system records or uploads speech audio, detects voice activity, reduces background noise, enhances speech quality, analyzes voice characteristics, and converts speech into text.



 ✨ Features

- 🎤 Record audio from microphone
- 📁 Upload audio file
- 🔊 Background noise reduction
- 🎚️ Speech enhancement
- 🗣️ Voice Activity Detection (VAD)
- 🎼 Pitch detection
- 📝 Speech-to-Text transcription
- 📊 Audio quality analysis
- 💾 Save enhanced audio
